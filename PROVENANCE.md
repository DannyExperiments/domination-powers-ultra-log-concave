2. **Freeze (25 November 2026).** The note was frozen with SHA-256 hashes before review.
3. **Independent computation.** The scripts in `verification/src/` were written by Claude without using the candidate's script.
4. **Audits (25–26 November 2026).** Three mathematical audit lanes and three literature lanes ran as separate Claude instances that did not see each other's conclusions. On 26 November, the published version of Galvin–Zhang showed the earlier Zheng–Qin claim, and the release was reframed as an independent proof.
5. **Manuscript and repository (25–26 November 2026).** Claude prepared these from the frozen proof and the audit repairs. The mathematics was not changed.
